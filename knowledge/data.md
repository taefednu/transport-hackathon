## Ловушки — на них легко потерять время

1. **BOM.** Ташкентский CSV — UTF-8 **с BOM**. Без `encoding="utf-8-sig"` первая колонка станет `﻿merchant`.
2. **Латинская `M` в номерах маршрутов.** 11 маршрутов записаны латиницей:
   `Mаршрут № 112, 136, 142, 143, 144, 151, 196, 23, 39, 52, 95`. Наивный `groupby("route")`
   даст 173 значения вместо 169 маршрутов + 4 линий метро.
3. **`station` — это линия метро, а не остановка.** 4 значения, пусто в 66.67%; для автобуса
   пусто на 100%. Реальные станции метро — в `dept_num` (`Чилонзор-1` → отсечь `-N`).
4. **Дубли в traffic.csv.** 17 851 строка — точные копии, размноженные по комбинациям
   `street`/`road_category`. Дедуплицировать по `(lat,lon,date,hour)` **до** любой агрегации,
   иначе загруженные улицы получат лишний вес. Готовый файл — `traffic_dedup.csv`.
5. **Два `pan_hash` — не люди.** `620D4A62…` = 113 611 транзакций (служебная transport_card),
   `A44C2D59…` = 62 992 (единый токен всех наличных). Всего 53 карты с >1000 поездок = 5.59%
   строк. Исключать перед любым счётом пассажиров.
6. **164, а не 328.** В `egov_tashkent_sched_fare.json` из 328 строк 164 — полные дубли.
7. **Транзакция ≠ пассажир.** Пересадки («Пересадка 0/700/1100») — отдельные транзакции той же
   поездки, 5.72%. `amount = 0` в 10.9% строк (льготы) — выручка обнулится, если не учесть.
8. **CRS шейпфайла Олмалика** — Sphere_Mercator, не EPSG:3857. Брать готовый
   `olmaliq_zones_wgs84.geojson`.

## Разрывы, которые не обойти

1. **Транзакции ↔ остановки автобуса — нет.** Поле пусто на 100%, координат нет. Полная
   OD-матрица Ташкента невозможна: система **tap-in only**, выходов не регистрирует.
2. **Транзакции Олмалика ↔ зоны Олмалика — нет** общего ключа. Модель валидировать нечем.
3. **`stations.csv` ↔ маршруты — нет** номеров, только `route_count`.
4. **Порядок остановок по маршруту** не выдан ни в одном файле. Добирать через Overpass API
   (Tashkent, `route=bus`, законно по ODbL) или парсингом tashtrans.uz. Полнота по 169 маршрутам
   не проверена.
5. **Плотности населения и контуров зданий в выданном датасете нет.** Нужен внешний слой —
   это ядро нашей метрики покрытия. Решено 07.08: **Kontur Population, H3 r8**, лицензия CC BY
   (атрибуция в подвале обязательна). Резерв — WorldPop 100 м с агрегацией в r8. Приёмка:
   сумма по гексагонам Ташкента = 3,18 млн ±10%. Подробности — `facts.md` §6, `decisions.md`.
6. **Официальных транспортных зон (TAZ) Ташкента в открытом доступе нет.** Придётся строить
   сетку или кластеры остановок и честно это называть.
7. **GPS-треков автобусов нет**, хотя обещаны на слайде трека. Спросить у менторов — могут
   выдать по запросу.

## Слабые места, о которых надо знать заранее

- Тренда и сезонности нет ни у кого: 1–3 дня или один срез.
- `auto_traffic` — безразмерный индекс, README прямо запрещает читать его как число машин.
- В traffic.csv нет направления движения — «в центр / из центра» не посчитать.
- Класс `green` в `stations.csv` — 80 строк из 2 872 (2.8%), для обучения практически пуст.

Нормализация номера маршрута (латинская `M`!):

```python
import re
def route_num(r):
    m = re.search(r"№?\s*([0-9]+[A-Za-zА-Яа-я]?)\s*$", r.replace("M", "М"))
    return m.group(1) if m else None
```

Станция метро из `dept_num`:

```python
station = re.sub(r"-\d+$", "", dept_num)   # 'Чилонзор-1' -> 'Чилонзор'
```

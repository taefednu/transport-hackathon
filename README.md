# QATNOV — цифровой двойник маршрутной сети Ташкента

Веб-инструмент, в котором изменение маршрутной сети пересчитывается в людей:
продлить маршрут, добавить остановку, обрезать, поменять интервал — и увидеть,
сколько человек получает доступ к транспорту, сколько теряет, как меняется время
до ближайшей остановки и во сколько машин обойдётся решение.

Проект National Transport Hackathon 2026, трек 1.

**Работающий стенд: https://qatnov-production.up.railway.app**

## Что считается

| Метрика | Значение | Как считается |
|---|---|---|
| PNT-500 | 3 043 073 — 95,8% | обслуживаемая остановка в 500 м **пешком по сети улиц** (СНиП 2.07.01-89) |
| Вне пешей доступности | 135 027 — 4,2%, 149 мест | то же |
| PNFT-15 | 2 698 759 — 84,9% | рядом маршрут с интервалом ≤ 15 мин (People Near Transit). Нижняя оценка |
| T-median | 3,11 мин | медиана времени пешком до остановки, взвешенная по населению |

Дельта сценария считается разностью множеств гексагонов, и всегда показываются
обе стороны: и кто получает доступ, и кто его теряет.

## Устройство

Весь тяжёлый счёт делается офлайн скриптами и складывается в parquet. Сервер при
старте загружает их в память и в момент запроса только читает и работает с
множествами. Базы данных нет, состояния нет: сценарий приходит целиком в теле
запроса и целиком возвращается в ответе — сервер ничего не применяет.

```
backend/app/        FastAPI и расчёты
backend/scripts/    пайплайн 00..09, run_all.sh, verify_gates.py
frontend/src/       карта и интерфейс: Vite + React + MapLibre
Dockerfile          ядро и интерфейс одним образом, один адрес
```

Приёмка — не юнит-тесты на моках, а 22 проверки по живому API одной командой:

```bash
cd backend
.venv/bin/python -m uvicorn app.main:app --port 8024
.venv/bin/python scripts/verify_gates.py 8024
bash scripts/run_all.sh          # пересобрать пайплайн, ~5 мин
```

Фронтенд:

```bash
cd frontend
npm install
npm run dev                      # адрес ядра — в .env
```

## Ассистент считает инструментами, а не отвечает из головы

`POST /api/assistant` устроен как диспетчер: модель выбирает инструмент,
движок считает, модель пересказывает посчитанное. **Числа она не производит.**

Готовый текст проверяется кодом: из него вытаскиваются все числа и сверяются с
числами результатов расчёта. Появилось лишнее — текст модели выбрасывается
целиком и отдаётся собранный кодом. Идентификаторы остановок подставляет поиск
по базе, а не модель, поэтому выдумать остановку структурно нельзя.

Модель может отвалиться: у каждого текстового эндпоинта есть детерминированный
путь, работающий без сети, и поле `source` показывает, каким путём получен ответ.

## Данные

**В этом репозитории данных нет и не будет.** Открыт только код. Датасет
организаторов, дамп OpenStreetMap, слой населения и все артефакты пайплайна
закрыты `.gitignore`: на чистом клоне работают чтение кода, импорт и проверки
синтаксиса, а расчёт заводится на своих данных.

Внешние открытые источники кладутся в `backend/data/external/`:
`uzbekistan-latest.osm.pbf` (Geofabrik) и слой населения.

Датасет организаторов выдан на их условиях: не распространять вне команды, не
публиковать, не пытаться связать псевдонимизированные идентификаторы карт с
людьми.

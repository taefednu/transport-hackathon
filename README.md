# Цифровой двойник маршрутной сети — песочница «что если»

Веб-инструмент, в котором изменение маршрутной сети Ташкента пересчитывается в людей:
продлить маршрут, добавить остановку, снять дублирование — и увидеть, сколько человек
получает доступ к транспорту, сколько теряет и как меняется время до ближайшей остановки.

Проект National Transport Hackathon 2026, трек 3 (данные Минтранса и Яндекса).
Полная формулировка — [`knowledge/product.md`](knowledge/product.md).

**Работающий стенд: https://qatnov-production.up.railway.app**

## Почему репозитория два

Этот репозиторий — **весь код продукта**, открытый по MIT. Данных в нём нет и не
будет, и это не небрежность, а условие: датасет выдан только для трека 3 и не
подлежит публикации. Поэтому на чистом клоне работают чтение кода, импорт и
проверки синтаксиса, а расчёт заводится на своих данных по инструкции ниже.

Но сервер без посчитанных артефактов не поднимается вообще. Поэтому рядом
существует **приватный репозиторий выкладки** `taefednu/qatnov-deploy`: тот же
код плюс 25 МБ артефактов пайплайна. Хостинг следит за его веткой `main`.

| | этот репозиторий | репозиторий выкладки |
|---|---|---|
| Видимость | публичный, MIT | приватный |
| Код | да | тот же, скопированный |
| Артефакты пайплайна | нет | да, 25 МБ |
| Выданный датасет, дамп OSM, ключи | нет | нет |
| Правится руками | да | **нет, генерируется скриптом** |

Приватный репозиторий собирается **перечислением, а не исключением**: скрипт
копирует ровно те файлы, которые читает `app/store.py`, и падает, если в
результате оказался `.env`, симлинк или сырой источник. Чего нет в списке —
того нет в выкладке. Так решение «что можно публиковать» принимается один раз
в одном месте, а не заново при каждом коммите.

Что уезжает в выкладку из выданных данных: координаты и названия остановок,
время хода по перегонам и сводка «маршрут × час → интервал, машин». Сырых
транзакций и идентификаторов карт там нет ни строки.

## Запуск

Все команды бэкенда — из каталога `backend/`.

```bash
cd backend
.venv/bin/python -m uvicorn app.main:app --port 8024   # сервер
.venv/bin/python scripts/verify_gates.py 8024          # приёмка всех гейтов ТЗ
bash scripts/run_all.sh                                # пересобрать пайплайн (~5 мин)
```

Фронтенд — из каталога `frontend/`:

```bash
cd frontend
npm install
npm run dev          # адрес ядра задаётся в .env, по умолчанию http://localhost:8025
```

## Выкладка на хостинг

Интерфейс и ядро едут одним образом и одним адресом: фронтенд собирается первой
стадией `Dockerfile` и раздаётся тем же сервером, поэтому кросс-доменных
запросов нет и адрес ядра во фронтенде пустой.

Одна команда — она пересобирает приватный репозиторий выкладки и пушит его,
а хостинг подхватывает пуш сам:

```bash
bash backend/scripts/sync_deploy.sh
```

Каталог назначения и адрес репозитория переопределяются переменными
`QATNOV_DEPLOY_DIR` и `QATNOV_DEPLOY_REMOTE`. Ключ модели задаётся переменными
окружения на стороне хостинга (`QATNOV_YC_API_KEY`, `QATNOV_YC_FOLDER_ID`);
без них сервер работает, а ассистент отвечает детерминированным путём.

Внешние источники кладутся в `backend/data/external/`: `uzbekistan-latest.osm.pbf` (Geofabrik) и
`kontur_population_UZ.gpkg` (HDX). Overpass API из этой сети недоступен — всё из локального дампа.

## Данные

`backend/data/raw` указывает на `/mnt/d/Transport Hackathon/track3_dataset`. Если симлинк битый
(другая машина, другой путь) — пересоздать:

```bash
ln -sfn "<путь до track3_dataset>" backend/data/raw
```

**В этом репозитории данных нет и не будет.** Открыт только код. Датасет
организаторов, дамп OSM, слой Kontur и все артефакты пайплайна закрыты
`.gitignore`: на чистом клоне работают импорт, тесты синтаксиса и чтение кода,
а расчёт заводится только на своих данных по инструкции выше.

Датасет выдан **только для трека 3**: не распространять вне команды, не публиковать,
не пытаться связать `pan_hash`/`masked_pan` с людьми. `.gitignore` закрывает весь `data/`
и все табличные/геоформаты — если понадобится закоммитить маленький выходной `.geojson`,
добавлять только через `git add -f` и только осознанно, убедившись, что это агрегат.

Разбор данных уже сделан: [`knowledge/data.md`](knowledge/data.md) и `backend/data/raw/track3_analysis.md`.
Читать разбор до того, как открывать файлы.
